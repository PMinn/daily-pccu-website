# 每日文大

每日文大是專為中國文化大學學生打造的 LINE Bot，把文大的每一天整理進一個對話框。從陽明山多變的天氣、公車即時進站資訊，到校內最新消息，打開 LINE 就能一次掌握，不用再多裝任何 App。

## 功能

- **天氣**：校內及多點氣象站的即時天氣資訊，以及一週內的天氣預報
- **公車**：公車的即時進站資訊
- **最新消息**：快速查看校內的重要訊息
- **吃什麼**：快速幫你決定要吃什麼
- **星座運勢**：查看每日的星座運勢
- **校園即景**：快速連接到學校的校園即景網頁
